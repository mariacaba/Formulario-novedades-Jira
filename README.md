# Formulario-novedades-Jira
A partir de un número de incidencia de Jira, la automatización obtiene y formatea el ID, el título y la descripción de la incidencia aplicando el formato definido (tipo y tamaño de letra), permitiendo copiar posteriormente el texto ya formateado y después filtra la release notes


La primera vez que ejecutamos la aplicación, nos pide crear un token para poder leer los datos informados en JIRA
